Endpoints API

Les endpoints backend Firebase pour l'application Android et le webhook paiement.

POST/api/devices/checkVérification du statut device — trial / premium / expiré + playlist assignée
GET/api/v1/playlist/:macRécupération de la playlist active pour une MAC address
GET/api/mac/check/:macVérification d'activation (boolean) pour une MAC donnée
POST/api/joboost-cashWebhook Joboost Cash — Réception des callbacks de paiement
GET/api/check-status?licenseId=xxxVérifier le statut de paiement d'une licence
GET/api/v2/reseller/:id/clientsListe des clients d'un revendeur spécifique
