votre réseau IPTV

Un backend complet avec dashboard admin, webhooks paiement et gestion des licences.

🎮

Dashboard Admin Complet

Vue d'ensemble en temps réel, gestion des activations, revendeurs et paiements. Interface glassmorphism avec animations ReactBits.

🔐

Licences & Activations

Gestion complète des licences premium et essai. Détection anti-reinstall via hardware fingerprint.

💳

Webhooks Paiement

Intégration Joboost Cash avec vérification signature HMAC. Idempotence, rate limiting, provider registry extensible.

🏪

Multi-Revendeur

Système de revendeurs avec API keys uniques. Chaque revendeur gère ses clients et voit ses statistiques.

📊

Métriques & Analytics

Dashboard temps réel avec compteurs animés, graphiques d'activité, taux de conversion et tendances.

🔒

Sécurité Backend

Rate limiting Firestore persistant, idempotence webhook, CORS configurable, API versionnée v1/v2, clés API dans Remote Config.

🔔

Notifications FCM

Push automatiques lors d'activation, d'expiration de trial et de nouvelles playlists. Canal dédié skyplayer_notifications.

⏰

Expiration Auto

Scheduled Function qui expire les trials et premiums dépassés toutes les 24h. Nettoyage automatique des tokens FCM.

Récupération de la playlist active pour une MAC address
